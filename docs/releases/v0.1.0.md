# benchpub v0.1.0

First public release of benchpub.

> Publish benchmark evidence, not just benchmark numbers.

## What ships

- versioned JSON result contract;
- path-aware result validation;
- baseline/treatment comparison;
- `compatible`, `incompatible`, and `indeterminate` comparability states;
- absolute and relative metric deltas;
- conservative higher/lower outcome semantics;
- machine-readable comparison JSON;
- deterministic Markdown reports;
- self-contained static HTML reports;
- exact input preservation with SHA-256 provenance;
- reproducible end-to-end example;
- CI across Python 3.11, 3.12, and 3.13.

## Product boundary

benchpub does not execute benchmarks.

It is not an experiment-tracking server, database, statistical significance engine, dashboard SaaS, or benchmark hosting platform.

Publication providers and optional notifications remain outside v0.1.0.

## Install

With uv:

```bash
uv tool install git+https://github.com/oalangomes/benchpub.git@v0.1.0
benchpub --version
```

Release assets also include a wheel and source distribution.
